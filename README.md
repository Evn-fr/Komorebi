# Komorebi
Komorebi (木漏れ日, meaning sunlight streaming through tree leaves) is a Waterfox fork for Android I made using Claude. It features :
<ul>
  <li>🍃Custom design</li>
  <li>🌫️Dynamic blur</li>
  <li>🚫No keyboard words learning, even in private mode (where text is not suggested, just like Samsung Browser for Android)</li>
  <li>🤳Custom gesture for a better use and experience</li>
  <li>☀️Custom loading screen when starting the app</li>
  <li>🕶️Default private mode</li>
  <li>🦊Mozilla Firefox extension (uBlock Origin, Privacy Badger)</li>
</ul>
